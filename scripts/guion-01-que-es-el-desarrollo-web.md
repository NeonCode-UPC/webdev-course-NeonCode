# Nivel 1: ¿Qué es el desarrollo web? (guion previsto de 5 min)

Editor: CodePen. La demostración comienza en blanco. La práctica compartida empieza con el saludo y el título de color tomate.

## 1. Portada (0:00 a 0:10)

PANTALLA: portada del nivel 1 con el ícono del globo terráqueo.

VOZ: "Bienvenido al curso de desarrollo web. En este primer nivel vas a descubrir de qué están hechas las páginas que visitas todos los días, y vas a cambiar una con tus propias manos. No necesitas instalar nada."

## 2. Pregunta gancho (0:10 a 0:40)

PANTALLA: tarjeta "¿Cómo se ve una página web por dentro?".

VOZ: "¿Cómo se ve una página web por dentro? Detrás de cada sitio que visitas hay código, y tú también puedes escribirlo." Haz 3 segundos de silencio.

## 3. Misión (0:40 a 1:05)

PANTALLA: "MISIÓN 01" con tres objetivos y la recompensa.

VOZ: "Tu misión: saber qué es un sitio web, conocer HTML y CSS y cambiar tu primera página. La recompensa: tu primera página web."

## 4. Una página es contenido más estilo (1:05 a 1:45)

PANTALLA: tres cajas: HTML (el contenido), CSS (el estilo) y Tu sitio. Haz que aparezcan una por una.

VOZ: "Toda página web se hace con dos lenguajes. HTML es el contenido: los títulos, los textos, las imágenes. Es como el esqueleto. CSS es el estilo: los colores, las fuentes, el diseño. Es como la ropa. HTML dice qué hay; CSS dice cómo se ve."

## 5. ¿Cómo llega una página a tu pantalla? (1:45 a 2:30)

PANTALLA: cuatro cajas: Tú, Navegador, Servidor, Pantalla. Anima cada paso en orden.

VOZ: "Cuando escribes una dirección, tu navegador, como Chrome o Safari, pide la página. Un servidor, que es un computador que guarda los sitios, la envía. Y tú la ves en tu pantalla. Un sitio web es un conjunto de páginas guardadas en un servidor."

## 6. Tu primer HTML (2:30 a 3:30)

PANTALLA: diapositiva con las dos líneas de código (10 s) y corte al editor.

EDITOR:

Muestra el pen vacío 2 segundos.

Haz clic en el panel HTML y escribe:

```html
<h1>¡Hola, web!</h1>
<p>Esta es mi primera página.</p>
```

En la vista previa aparece un título grande y un párrafo debajo.

VOZ: "Escribo mi primera etiqueta: h1 es el título principal. Debajo, p es un párrafo. Cada etiqueta se abre y se cierra. Mira cómo la vista previa cambia sola mientras escribo."

## 7. Tu primer CSS (3:30 a 4:15)

EDITOR:

Haz clic en el panel CSS y escribe:

```css
h1 {
  color: tomato;
}
```

El título cambia a color tomate.

VOZ: "Ahora el estilo. h1 es a quién quiero cambiar, y color es lo que cambio: lo pongo en tomate. Mira cómo cambia al instante."

## 8. Quiz: ¿qué da estilo a la página? (4:15 a 4:35)

PANTALLA: opciones A: HTML, B: CSS, C: El navegador.

VOZ: "¿Qué da estilo a la página?" (4 segundos) "Respuesta: B, CSS."

## 9. Pausa y tu turno (4:35 a 4:55)

PANTALLA: "PAUSA · TU TURNO" con los tres pasos.

VOZ: "Pausa el video. Cambia el título por tu nombre y cambia tomato por royalblue. Mira qué pasa."

## 10. Resumen (4:55 a 5:15)

VOZ: "Una página se hace con HTML y CSS. HTML es el contenido, CSS es el estilo, y el navegador muestra lo que escribes."

## 11. Reto final (5:15 a 5:30)

VOZ: "Tu reto: personaliza tu primera página. Escribe tu nombre en el título, cambia su color y agrega un párrafo sobre ti. En el siguiente nivel aprendes HTML a fondo."
